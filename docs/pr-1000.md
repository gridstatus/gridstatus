# PR #1000: thank you for building Grid Status with us

We made it to [PR #1000](https://github.com/gridstatus/gridstatus/pull/1000).

Behind that round number are people who added a dataset they needed, tracked down a timestamp that did not look right, wrote a clearer example, or stayed with a bug until someone else could reproduce it. Thank you for making open-source Grid Status better, one contribution at a time.

Electricity data gives us plenty to work on. Markets change, report formats move, and sometimes the same hour happens twice. A shared library means each person who solves one of those problems can save the next person the trouble.

## A few stops along the way

Our [first PR, #2](https://github.com/gridstatus/gridstatus/pull/2), was a README update by [jikac](https://github.com/jikac), opened on August 3, 2022. Documentation was there from the start.

A few examples of what followed:

- [#7](https://github.com/gridstatus/gridstatus/pull/7) added locational marginal price data for CAISO, NYISO, MISO, and ISO-NE; [#47](https://github.com/gridstatus/gridstatus/pull/47) expanded interconnection queue access.
- [#216](https://github.com/gridstatus/gridstatus/pull/216) added an EIA API v2 client, and [#306](https://github.com/gridstatus/gridstatus/pull/306) brought in an IESO scraper.
- [#615](https://github.com/gridstatus/gridstatus/pull/615) introduced an AESO API integration.
- [#933](https://github.com/gridstatus/gridstatus/pull/933) recovered ERCOT interconnection queue columns hidden behind merged spreadsheet headers. Sometimes better data access starts with untangling a spreadsheet.
- [#989](https://github.com/gridstatus/gridstatus/pull/989) and [#990](https://github.com/gridstatus/gridstatus/pull/990) tackled ERCOT's repeated daylight-saving hour. Even after hundreds of PRs, time still finds ways to be interesting.

Today, the library covers nine grid operators—CAISO, ERCOT, PJM, MISO, SPP, NYISO, ISO-NE, IESO, and AESO—plus the U.S. EIA. Available datasets range from load, fuel mix, and prices to forecasts, outages, and interconnection queues, with coverage varying by source. See the [API reference and examples](https://opensource.gridstatus.io/).

## What comes next

The next chapter will be shaped by the people using the library. There is plenty worth working toward: broader dataset coverage, clearer examples, stronger handling of upstream changes, and an easier path from finding a problem to making a first contribution.

If you have an idea, [open an issue](https://github.com/gridstatus/gridstatus/issues) and tell us what you are trying to do. A small reproducible bug report, a missing example, or a test for an awkward edge case is a useful place to start. The [contributing guide](https://github.com/gridstatus/gridstatus/blob/main/CONTRIBUTING.md) explains how to get involved.

Thank you for getting us here. Here's to the next contribution.
